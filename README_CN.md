# ComfyUI 分段队列运行器 (Segment Queue Runner)

专为高精度 AI 视频生成、长视频拼接以及流畅卡点变装工作流量身定制的 ComfyUI 自定义节点。提供精准的分段控制、平滑的过渡渲染以及完全自动化的队列续跑机制。

---

### 🚨 V3.0 重大更新内容
* **生态全面对齐**：完美适配并深度兼容 [ComfyUI-WanAnimatePlus](https://github.com/wuwukaka/ComfyUI-WanAnimatePlus) 节点。全面停用对旧版 WanVideoWrapper 的支持。
* **全新三大分段模式（可在设置中自由切换）**：
  1. **【平均分段】**：输入目标分段数，自动完成均分计算。
  2. **【手动分段】**：生成类似“视频编辑软件轨道”的交互式可视化微调框，并内置**视频预览功能**，专为音视频精准卡点、节奏对齐打造。
  3. **【固定帧数分段】**：指定每段的固定帧数，系统自动切分总段数。
* **极速无损合并（免重编码）**：修复了旧版强制重编码的 Bug。当各视频分段的 FPS、时间基等参数完全一致时，直接触发**零等待无损秒合并**。
* **进阶本地视频参考**：支持直接通过绑定节点 ID 引入本地准备好的骨骼（POSE）和面部（FACE）参考视频。在重复制作同款舞蹈动作或循环动画时，**彻底免去**重复采集图像的时间。
* **全场景自动续跑**：自动续跑、异常中断恢复等高级队列功能已全量适配三种全新的分段模式。
* 🐱 **隐藏彩蛋**：等待你在代码和实际使用中探索。

---

### 💡 核心基础功能（原有功能保留）
* **自动化超长视频拼接**：突破显存（VRAM）极限，将超长视频切分为多段进行分批次渲染，最终自动融合成无缝的长视频大片。
* **丝滑角色变装/转场逻辑**：专为角色换装、场景切换设计的平滑过渡机制，确保在队列切换时画面不会出现突兀的闪烁或断层。
* **智能队列管理**：杜绝 ComfyUI 渲染闲置，根据预设的逻辑关卡自动触发下一段任务，实现全自动无人值守续跑。

### 📦 安装方法
1. 进入你的 ComfyUI 插件目录：`ComfyUI/custom_nodes/`
2. 克隆本仓库：
   git clone https://github.com/FX-FeiHou/Comfyui-Segment-Queue-Runner.git
3. 安装必要依赖：
   pip install -r requirements.txt
4. 重启 ComfyUI 服务，并在浏览器端按下 `Ctrl + F5` 强刷页面以加载全新的 JS 交互逻辑。
