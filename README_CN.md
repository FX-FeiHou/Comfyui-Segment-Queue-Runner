# ComfyUI 分段队列运行器 (Segment Queue Runner)

[🇬🇧 English Version (英文说明)](./README.md)

---
专为高精度 AI 视频生成、长视频拼接以及流畅卡点变装工作流量身定制的 ComfyUI 自定义节点。提供精准的分段控制、平滑的过渡渲染以及完全自动化的队列续跑机制。

---

### 🚨 V3.6 更新日志
* 兼容旧工作流，参数空白也不会报错。
* 帧数、帧率支持自动识别，不用手动填写。
* 打开、保存工作流自动补齐参数，防止运行异常。
* 切换页面后节点控件不会错乱移位。
* 中断生成提示统一放在续跑按钮旁，界面整洁。
* 关闭续跑后提示直接消失，可正常开启新任务。
* 关闭续跑自动清除断点缓存，避免数据冲突。
* 新增进度清理功能，不会残留旧中断、报错提示。

---

### 💡 核心基础功能（原有功能保留）
* **自动化超长视频拼接**：突破显存（VRAM）极限，将超长视频切分为多段进行分批次渲染，最终自动融合成无缝的长视频大片。
* **丝滑角色变装/转场逻辑**：专为角色换装、场景切换设计的平滑过渡机制，确保在队列切换时画面不会出现突兀的闪烁或断层。
* **智能队列管理**：杜绝 ComfyUI 渲染闲置，根据预设的逻辑关卡自动触发下一段任务，实现全自动无人值守续跑。

---

### 📦 安装方法
1. 进入你的 ComfyUI 插件目录：`ComfyUI/custom_nodes/`
2. 克隆本仓库：
   git clone https://github.com/FX-FeiHou/Comfyui-Segment-Queue-Runner.git
3. 安装必要依赖：
   pip install -r requirements.txt
4. 重启 ComfyUI 服务，并在浏览器端按下 `Ctrl + F5` 强刷页面以加载全新的 JS 交互逻辑。
